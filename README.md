# My Vault — คลังร่วม

My Vault เป็นเว็บไซต์ภาษาไทยสำหรับเก็บไฟล์ ลิงก์ Prompt ปลั๊กอินและธีม คีย์เวิร์ด SEO เช็กลิสต์ ทีม โปรเจกต์ รายการหนัง และโพส พร้อมเครื่องมือแปลงข้อมูล นำเข้า Collector ค้นหาข้อมูล และส่งออก CSV, XLSX, JSON และ ZIP โดยคงหน้าตาและเมนูจากเว็บไซต์ที่แนบมา

ผู้ใช้ต้องสมัครสมาชิก ยืนยันอีเมล และเข้าสู่ระบบก่อนดูหรือแก้ไขข้อมูลในคลังร่วม ปุ่มจัดการข้อมูลใช้แก้ไขรายการทุกหมวด ปุ่มสำรอง JSON ส่งออกข้อมูลข้อความทุกหมวด (ไม่รวมไฟล์อัปโหลด) และปุ่มนำเข้าข้อมูลสำรองรวมรายการกลับเข้าคลังโดยไม่ลบรายการอื่น

## เทคโนโลยี

หน้าเว็บ HTML/CSS/JavaScript, Tailwind ผ่าน CDN, SheetJS และ JSZip พร้อม Netlify Functions (TypeScript), Netlify Database (Postgres, Drizzle ORM) สำหรับข้อมูล และ Netlify Blobs สำหรับไฟล์

## เริ่มต้นบนเครื่อง

```sh
npm install
npx netlify dev --port 8889
```

เชื่อมโปรเจกต์กับ Netlify ก่อนใช้งานระบบฐานข้อมูลและ Blobs หน้าต้อนรับและไฟล์ JavaScript/CSS อยู่ใน `site/` ส่วนหน้าเครื่องมือเดิมอยู่ใน `private/vault.html` และส่งผ่าน Function ที่ตรวจสอบสมาชิก ณ `/work` เท่านั้น และไม่มีขั้นตอน build สำหรับ frontend สร้าง migration เมื่อแก้ schema ด้วย `npx drizzle-kit generate --name describe_change` โดยระบบ deploy เป็นผู้ apply migration

## การใช้งานและข้อจำกัด

รอแถบสถานะแสดงว่าบันทึกบนคลาวด์แล้วก่อนปิดหน้า ถ้าเครือข่ายขัดข้อง ให้เปิดหน้าไว้และกดลองบันทึกอีกครั้ง ปุ่มโหลดข้อมูลล่าสุดดึงข้อมูลร่วมจากเซิร์ฟเวอร์ การแก้ไขคนละรายการถูกรวมกันบนเซิร์ฟเวอร์ ส่วนการแก้ไขรายการเดียวกันใช้ข้อมูลที่ส่งถึงทีหลัง

ไฟล์รองรับสูงสุด 10 MB ต่อไฟล์ โดยอัปโหลดเป็นส่วนย่อยและดาวน์โหลดแบบสตรีม การค้นหาออนไลน์และรูปใน ZIP ขึ้นกับเว็บต้นทาง หากรูปโหลดไม่ได้ ZIP ยังคงมี metadata และรายการ URL พร้อมระบุรูปที่ดาวน์โหลดไม่สำเร็จ การส่งออก XLSX/ZIP และรูปแบบหน้าเว็บต้องเข้าถึง CDN ภายนอกได้

ข้อมูลตัวอย่างและเมนูเริ่มต้นถูกนำมาจากไฟล์แนบ ข้อมูลที่เคยอยู่ใน localStorage/IndexedDB บนเว็บไซต์เดิมไม่ได้ถูกย้ายอัตโนมัติ สามารถใช้การส่งออก/นำเข้าของหมวดโพสและ Collector ได้


## สมาชิกและพื้นที่ทำงาน

หน้าต้อนรับ `/` รองรับสมัครสมาชิก เข้าสู่ระบบ ยืนยันอีเมล และตั้งรหัสผ่านใหม่ผ่าน Netlify Identity สมาชิกใช้คลังและเครื่องมือเดิมร่วมกันโดยมีสิทธิ์ดูและแก้ไขเท่ากัน API ทุกตัวตรวจสอบการเข้าสู่ระบบ รวมถึงการดาวน์โหลดไฟล์และส่งออกภาพ รายชื่อสมาชิกแสดงเฉพาะชื่อ ไม่เปิดเผยอีเมล

หน้าหลักของพื้นที่ทำงานแสดงสมาชิกทั้งหมดและสถานะออนไลน์ โดยส่งสัญญาณทุก 30 วินาทีขณะเปิดหน้าอยู่ และถือว่าออฟไลน์เมื่อไม่มีสัญญาณเกิน 90 วินาที แต่ละแท็บมีสถานะแยกกัน ปุ่มออกจากระบบรอการบันทึกข้อมูลในคิวก่อน หากเซสชันหมดอายุ สามารถเปิดหน้าเข้าสู่ระบบในแท็บใหม่แล้วกลับมาลองบันทึกได้ การรีเฟรชสถานะสมาชิกไม่โหลดข้อมูลคลังใหม่ ให้ใช้ปุ่มโหลดข้อมูลล่าสุดสำหรับข้อมูลจากเพื่อนร่วมทีม

ข้อมูลสมาชิกและสัญญาณออนไลน์เก็บใน Netlify Database ส่วนข้อมูลเข้าสู่ระบบดูแลโดย Netlify Identity มี migration ใหม่สำหรับตารางสมาชิกและสถานะ โดยคง migration เดิมไว้ Browser SDK ถูกตรึงเวอร์ชันและเก็บใน `site/vendor/identity/` เพื่อไม่ต้องโหลดระบบสมาชิกจาก CDN ตอนใช้งาน
