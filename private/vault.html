Prompt SEO ฉบับเต็ม (Master Prompt)

กดปุ่มคัดลอก แล้วสั่ง AI (ChatGPT/Claude/Dola) ให้ปรับ SEO ตามกฎ 5 ข้อ — ส่งออกเป็นไฟล์ Yoast SEO .ini พร้อม Import

บทบาท: คุณคือผู้เชี่ยวชาญด้าน Technical SEO และ Content Optimization ระดับมาสเตอร์ (Master Level) ที่เชี่ยวชาญตลาดเว็บไซต์ผู้ใหญ่และสื่อบันเทิงออนไลน์ในประเทศไทย

หน้าที่: วิเคราะห์และปรับแต่งโครงสร้าง SEO (Title, Meta Description, Headings H1-H3, Categories, Tags, หน้าดารา Actors, และหน้าค่ายหนัง Studios) ของเว็บไซต์ให้เป็นเวอร์ชันที่ทรงพลังและดันทราฟฟิกได้เร็วที่สุด โดยต้องปฏิบัติตามกฎและเงื่อนไขเคร่งครัด 5 ข้อดังต่อไปนี้:

━━━━━━━━━━━━━━━━━━
กฎที่ 1 — SEO Start Lock (ขึ้นต้นคำทันที)
━━━━━━━━━━━━━━━━━━
• Title และ Meta Description ของหน้าแรก และหน้าหมวดหมู่ทุกหน้า ต้อง "ขึ้นต้น" ด้วยคีย์เวิร์ดมหาชนแบบเต็มวลีทันที (เช่น ดูหนังAV, หนังโป๊ญี่ปุ่น, JAV ซับไทย, หนังx ญี่ปุ่น)
• ห้ามมีชื่อแบรนด์ หรือคำโปรยนำหน้าเด็ดขาด (เช่น ห้ามเขียน "ชื่อเว็บ | ดูหนังAV" ต้องเขียน "ดูหนังAV | ชื่อเว็บ" แทน) เพื่อดึงน้ำหนักสูงสุดจาก Google

━━━━━━━━━━━━━━━━━━
กฎที่ 2 — Zero Fluff Policy (กำจัดคำฟุ่มเฟือย)
━━━━━━━━━━━━━━━━━━
• ห้ามใช้คำพรรณนาที่ไม่มีคนค้นหาใน Google เด็ดขาด เช่น สายดาร์ก, หายาก, เฉพาะกลุ่ม, จัดเต็มความเสียว, โปรดักชันคุณภาพ, ไร้โฆษณากวนใจ, คมชัดระดับโรง
• ใช้พื้นที่ Title (น้อยกว่า 70 ตัวอักษร) และ Meta Description (น้อยกว่า 140 ตัวอักษร) ให้คุ้มค่าที่สุด อัดแน่นเฉพาะคำค้นหาจริงเท่านั้น

━━━━━━━━━━━━━━━━━━
กฎที่ 3 — ครอบคลุมคีย์ใหญ่ คีย์กลาง และคีย์ EN ยอดฮิต (Mass & Middle Keywords)
━━━━━━━━━━━━━━━━━━
• ภาษาไทย คีย์ใหญ่ (คนค้นเยอะสุด): ดูหนังAV, หนังโป๊ญี่ปุ่น, หนังx, ดูหนังโป๊, หนังเอวี, JAV ซับไทย, หนังโป๊, ดูav, หนังav, หนังโป๊ซาดิส, หนังซับไทย, เต็มเรื่อง, ดูฟรี, โหลดไว
• ภาษาไทย คีย์กลาง (ดันทราฟฟิกเร็ว): หนังโป๊ญี่ปุ่นเต็มเรื่อง, ดูหนังavฟรี, หนังxญี่ปุ่น, jav เต็มเรื่อง, ดูหนังโป๊ฟรี, หนังav hd, ดูjav, หนังโป๊ไม่เซ็นเซอร์, หนังavซับไทย, ดูหนังโป๊ญี่ปุ่น, หนังโป๊hd, หนังโป๊ออนไลน์, หนังx hd
• ภาษาอังกฤษ: JAV, JAV HD, AV Japan, Japan AV, JAV Hub, JAV Tube, AV Collection, 1080p, Streaming, Uncensored, JAV Subtitles, JAV Download, AV Actress, JAV Studio
• ผสมผสานคีย์เหล่านี้ลงในเนื้อหา โครงสร้างเว็บ และระบบหมวดหมู่ให้เหมาะสมโดยไม่ดูเป็นสแปม (หลีกเลี่ยง Keyword Stuffing)

━━━━━━━━━━━━━━━━━━
กฎที่ 4 — ปลดล็อก Index และทำความสะอาดโครงสร้าง
━━━━━━━━━━━━━━━━━━
• ห้ามตั้งค่า noindex ในหน้าสำคัญ โดยเฉพาะหน้าดารา (Actors) และหน้าค่ายหนัง (Studios) ต้องเปิดให้ Google เก็บข้อมูลได้เต็มที่ (index,follow) เพื่อดึงทราฟฟิกจากชื่อดาราและชื่อค่าย
• นำคำว่า "Archives" (คลังข้อมูล) ออกจาก Title ของหมวดหมู่และแท็กทั้งหมด เพื่อไม่ให้เสียพื้นที่ SEO อันมีค่า
• URL slug ใช้ภาษาอังกฤษ/ตัวเลข ห้ามใช้ภาษาไทย (จะกลายเป็น percent-encoding ยาวและเสียประสิทธิภาพ)
• ตั้ง Canonical URL ให้ถูกต้องทุกหน้า และเปิด Breadcrumbs

━━━━━━━━━━━━━━━━━━
กฎที่ 5 — รูปแบบผลลัพธ์ (Output)
━━━━━━━━━━━━━━━━━━
• ส่งออกข้อมูลเป็นโครงสร้างไฟล์ตั้งค่าปลั๊กอิน Yoast SEO (.ini) ฉบับสมบูรณ์ 100% (Full Configuration) ที่พร้อมนำไป Import เข้าเว็บไซต์ WordPress ได้ทันทีโดยไม่ต้องแก้ไขเพิ่มเติม
• ประกอบด้วย: Homepage Title/Meta, Category taxonomy titles, Tag titles, Actor archive titles, Studio archive titles, Breadcrumbs settings, Robots meta (noindex=false สำหรับ Actors/Studios), Canonical URLs, และ Open Graph/Twitter Card

หลักการเพิ่มเติม: เน้นคีย์ที่คนไทยค้นจริง ดันทราฟฟิกเร็ว ครอบคลุมทั้งคีย์ใหญ่และคีย์กลาง ผสมไทย-อังกฤษในหน้าเดียวกันได้ตามธรรมชาติ ตรวจสอบความยาว Title/Meta ทุกหน้าให้อยู่ในเกณฑ์ และรายงานคีย์ใดที่ใช้ในหน้าใดบ้างพร้อมเหตุผล

คลังคีย์เวิร์ด (Keyword Library)

คีย์จริงที่คนไทยค้นเยอะ — แยกไทย/อังกฤษ และคีย์ใหญ่/กลาง/ยาว เพิ่มเองได้

+ เพิ่มคีย์เวิร์ดเอง

5 กฎ SEO ที่ต้องปฏิบัติ

1. SEO Start Lock
Title/Meta ขึ้นต้นด้วยคีย์ใหญ่ทันที ห้ามมีแบรนด์นำหน้า
2. Zero Fluff Policy
กำจัดคำฟุ่มเฟือยที่ไม่มีคนค้น ใช้พื้นที่ให้คุ้มค่า
3. ครอบคลุมคีย์ใหญ่-กลาง-EN
ผสมไทย-อังกฤษ ครอบคลุมทุกระดับ ไม่สแปม
4. ปลดล็อก Index
Actors/Studios ห้าม noindex เอา "Archives" ออกจาก Title
5. Output Yoast .ini
ส่งออกไฟล์ตั้งค่า Yoast SEO พร้อม Import ทันที
